## Мой сайт-портфолио
 [Сайт-портфолио](https://vsetutshop.ru) - мой личный сайт-портфолио. На данный момент развёрнут на моём личном сервере на отдельной **Proxmox** виртуалке. В интернет смотрит через тунель **CloudPab**.
 
Back-end в данный момент написан на **Golang** с базой данных **PostgreSQL** и использованием **Kafka** и **Kubernetes**.

Для деплоя были использованы: **Proxmox**, **Docker**, **Ngnix**, **CI / CD (GH ACTIONS)**.

Front-end написан на **Next.js** с использованием **Redux**, **TypeScript**, **Sass**, **TailWind** и технологией **Server Side Rendering** и тестирование с помощью **Next.js**.

Так же была реализована панель администратора на **Express.js**. Реализована проверка CRTF токена, защита от XSS.

Ранее Back-end был написан на **Java** (с использованием **Spring**), на **Python** (с использованием **Django**), на **JavaScript**  (с использованием **Express.js**).
